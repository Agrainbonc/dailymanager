# 课程文件自动分类

## 输入与归档

用户只需配置一个统一投递目录。根目录中的受支持文件会在扫描或文件监听触发后被移动到以下位置：

```text
投递目录/
  高等数学/
    2026-09-16/
      source/
        高数_极限_2026-09-16_08-30.m4a
  needs-review/
    2026-09-16/
      source/
        课堂录音_2026-09-16_08-30.m4a
```

已归档的 `课程/日期/source` 文件会被扫描器忽略，重复扫描不会再次归档同一份文件。文件使用 SHA-256 去重；相同内容不会重复进入资料库。

## 判定信号

每个课程可以设置课程名、文件名别名、关键词和每周上课时间段。分类器按以下信号累计评分：

| 信号 | 分值 | 说明 |
| --- | ---: | --- |
| 课程名 | 90 | 课程名直接出现在文件名中 |
| 别名 | 82 | 例如“高数”或“Calculus” |
| 关键词 | 66 | 例如“极限”“卷积” |
| 课表精确匹配 | 68 | 文件名中的时间落在该课程上课时段内 |
| 课表邻近 | 28-46 | 与课程开始或结束时间相差不超过 90 分钟 |

文件名可识别 `2026-09-16`、`20260916`、`2026年9月16日` 等日期，以及 `08:30`、`0830`、`8点30分` 等时间。缺少文件名时间时，才以文件修改时间作为较弱依据。

## 置信度和人工确认

只有最高候选达到 60 分，且领先第二候选至少 14 分时，系统才会自动归档；达到 85 分的强匹配可直接归档。没有候选、课表重叠、关键词同时命中多个课程等情况会进入 `needs-review`。界面会显示判定原因，并允许用户选择正确课程；选择后文件会移动到该课程目录，记录为“已手动归类”。
