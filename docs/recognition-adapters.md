# 识别适配器契约

## ASR

输入：本地音频路径、语言提示、是否开启说话人分离。

输出：全文、音频时长、语言、分段列表。每个分段必须有 `start_ms`、`end_ms`、`text`，可选 `confidence` 和 `speaker`。

首选实现为本地 `faster-whisper`，以获得可靠的原生时间戳。云端 Paraformer 或音频理解模型作为可选提供方，不用模型生成的估算时间戳替代 ASR 原始时间戳。

## PPT 视觉理解

输入：PPTX 页面文字、页码、页面图片或嵌入图片、相邻文字上下文。

输出：结构化视觉说明，包含页面摘要、图表/流程/公式解释、关键术语、置信度和不确定性说明。

默认先提取 `python-pptx` 中的原生文字；视觉模型只处理内嵌图片、文字不足的页面或用户明确要求解释的页面。旧版 `.ppt` 与整页渲染需要可选 LibreOffice 支持，不能作为轻量安装包的硬依赖。
