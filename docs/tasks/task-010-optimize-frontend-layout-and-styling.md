## 任务目标
1. **前端文件排布与多维有序分类**：
   - 支持同一门课内资料按时间（正序/倒序）或名称、大小严格排列；
   - 支持多维分类呈现：【时间轴/日期分组模式】、【资料类型分组模式】、【全览时按课程归属分组模式】与【紧凑平铺列表模式】；
   - 提供文件名关键字即时检索、类型胶囊筛选（全部/录音/课件/待确认）及排序维度切换。
2. **样式重构与视觉现代化**：
   - 采用现代化学术与知识库设计语言（Clean Academic & Productivity），更新整体配色系统、字体层次、卡片层次、阴影与圆角；
   - 优化深色侧边栏（品牌 Logo 质感、活跃指示条、课程资料计数徽标、快速设置入口）；
   - 优化工作台 Header（课程排课时段胶囊、ASR/Vision 状态灯徽章、概览指标卡片视觉微动效）。
3. **增强可操作性与交互功能**：
   - 支持【列表视图】与【网格卡片视图】无缝切换；
   - 增加音频在线试听播放能力（后端支持资料文件获取，前端支持直接试听播放）；
   - 增加每项资料的行内/卡片快捷操作：一键试听、一键下载源文件、一键触发/重新转写、一键复制解析文本、快速重新归类；
   - 增加批量选择与批量导出（支持多选资料后打包下载源文件或 ASR 文本）；
   - 任务队列可视化增强（进度条动效、阶段标签、折叠收起控制）；
   - 现代化 Toast 通知与弹窗遮罩交互。
4. **自检与验证**：
   - 运行前端 `npm run build` 确保 TypeScript 类型与模板零错误；
   - 运行后端 `unittest` 确保所有 API 与接口自测通过。
