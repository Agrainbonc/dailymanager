# DailyManager Windows 使用说明

## 启动

1. 解压 `DailyManager-Windows-x64.zip`，不要直接在压缩包内运行。
2. 双击 `DailyManager/DailyManager.exe`。
3. 程序会启动本地服务并自动打开浏览器；关闭黑色运行窗口即可停止服务。

程序只监听 `127.0.0.1:8000`，不会向局域网或公网开放。首次启动会在程序目录生成 `data/`，其中保存日历、任务、课程和资料索引。升级或迁移时请保留这个目录。

## 导入学习计划

进入“日历日程”，点击“导入学习计划”。建议先下载 Excel 模板，再填写以下列：

- `日期`：如 `2026-10-29`
- `学习任务`：必填
- `开始时间`、`结束时间`：如 `09:00`
- `分类`、`优先级`、`预计分钟`、`备注`、`是否完成`：可选

支持 `.xlsx`、`.xls`、`.csv` 和 `.json`。相同日期、任务名称和开始时间的记录会自动跳过，避免重复导入。

## 阿里云录音转写

在“系统设置 → ASR 语音转写服务设置”中选择“阿里云 API (DashScope)”，在本机填写 API Key，选择 `qwen-audio-turbo` 并测试连接。API Key 保存在本机数据库中，请勿发送给他人；不同用户应使用各自的 Key。

## 数据备份

退出程序后复制整个 `data/` 目录即可完成备份。恢复时将备份目录放回 `DailyManager.exe` 同级位置。
